## 🚀 Featured Project

# 🌌 [Project Orion](https://github.com/DevianEddins/Project-Orion)

**Enterprise Hybrid Identity & Access Management Lab**

Project Orion is an enterprise-inspired IAM environment built using Active Directory, Windows Server, Microsoft Entra ID, PowerShell, and Git.

The project demonstrates how an organization can provision identities, manage employee changes, securely remove access, audit identity risks, certify entitlements, remediate access, and prepare an on-premises directory for hybrid cloud identity.
